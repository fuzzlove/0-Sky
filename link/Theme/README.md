# 0-Sky Link color themes

Link offers Ocean Blue, Classic Green, Ember Red, Violet, and Monochrome in
the Start screen and research console. The choice persists in the app's local
preferences (`ZeroSkyLinkThemeID`) and colors only the presentation layer.
Status results, trust checks, and access gates do not use theme colors as
their source of truth. Classic Green remains the default for existing users.

The choices reflect broad color preference research, not a claim that these
exact UI palettes were surveyed. In a 2015 YouGov survey of 10,866 people
across ten countries, blue was the most selected favorite in every country;
green, red, and purple appeared among other favored colors, with preferences
varying by country and demographic. The neutral option preserves a restrained
high-contrast look. Source:
https://yougov.com/en-us/articles/12335-why-blue-worlds-favorite-color
